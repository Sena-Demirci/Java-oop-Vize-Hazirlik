## Java OOP Vize Hazırlık Reposu
Java Nesne Yönelimli Programlama dersi vize sınavı için hazırlanan kod örnekleri ve ders notları.

* Modul\_1.java : Java Mimarisi, Primitif/Referans Türler, Tip Dönüşümleri
* Modul\_2.java : Kapsülleme (Encapsulation), Erişim Belirleyiciler, GC
* Modul\_3.java : Yapıcılar (Constructors), this(...) Zinciri, final Belirteci
* Modul\_4.java : static Üyeler, Factory Metotlar, Bileşim, İç İçe Sınıflar
